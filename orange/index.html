Roles de Datos en Orange

Feature (Característica)

Variables independientes o atributos que se usan para hacer predicciones.

Ejemplos:

  • Departamento de Nacimiento
  • Nivel Educativo
  • Sector Administrativo
  • Meses de Experiencia Independiente
  • Clasificación Orgánica
  • Tipo Entidad
  • Naturaleza Jurídica
  • 9. Tipo de Nombramiento
  • 10. Fecha de Vinculación

Target (Objetivo)

Variable dependiente, es decir, lo que quieres predecir.

Ejemplos:

  • Nivel Jerárquico Empleo

Meta (Dato informativo)

Columnas que no se usan en el modelo, pero sirven para identificar o describir.

Ejemplos:

  • Sexo
  • Orden
  • Suborden
  • Departamento Ubicación Entidad
  • Municipio de Nacimiento
  • Meses de Experiencia Público
  • 7. Meses de Experiencia Privado
  • Meses de Experiencia Docente
  • Municipio Ubicación Entidad
  • 11. Denominación Empleo Actual
  • Dependencia Empleo Actual
  • Nombre Entidad
  • Asignación Básica Salarial

Skip (Ignorar)

Columnas que no se van a usar en absoluto.

Ejemplos:

  • Nombre
  • ID Departamento de Nacimiento
  • ID Municipio de Nacimiento
  • Email Oficina
  • Código Sigep
  • Número de Identificación
  • ID Municipio Entidad
  • Latitud Municipio Entidad
  • Longitud Municipio Entidad
  • ID Departamento Entidad
  • NIT Entidad

Widgets Utilizados

File Widget

Carga y abre archivos de datos para análisis. Primer paso esencial en cualquier flujo de trabajo.

Uso en el proyecto:

Importar el conjunto de datos de servidores públicos desde datos.gov.co

Data Table

Visualiza de forma tabular el contenido del conjunto de datos.

Uso en el proyecto:

Mostrar los registros procesados durante todo el proceso de analisis.

Data Sample

Genera un muestreo del conjunto de datos para agilizar el procesamiento.

Uso en el proyecto:

Crear muestra del 70% del conjunto de datos original

Python Script

Permite ejecutar código Python personalizado para manipular datos.

Uso en el proyecto:

Limpiar datos eliminando valores nulos, y asimismo a sumar experiencia laboral total

Edit Domain

Permite modificar los tipos de variables y sus atributos en el conjunto de datos.

Uso en el proyecto:

Definir variables categóricas y numéricas para el análisis

Preprocess

Aplica transformaciones estándar a los datos como normalización, imputación de valores faltantes, etc.

Uso en el proyecto:

Estandarizar rangos de valores y manejar datos faltantes

Select Rows

Filtra el conjunto de datos basado en condiciones específicas aplicadas a las filas.

Uso en el proyecto:

Seleccionar solo filas donde: experiencia (público, privado, independiente, docente) tenga valores no nulos

Select Columns

Selecciona un subconjunto de columnas específicas del conjunto de datos.

Uso en el proyecto:

Extraer solo las variables relevantes para nuestro análisis.

Tree

Implementa un clasificador de árbol de decisión para modelar relaciones en los datos.

Uso en el proyecto:

Predecir el nivel jerárquico basado en features, target y meta.

Random Forest

Ensemble de múltiples árboles de decisión que mejora la precisión predictiva.

Uso en el proyecto:

Modelar la relación entre experiencia y nivel jerárquico con mayor precisión.

Tree Viewer

Visualiza interactivamente la estructura de un árbol de decisión generado.

Uso en el proyecto:

Analizar las reglas de decisión del modelo creado y mostrarlo graficamente.

Pythagorean Tree

Visualización especializada para mostrar jerarquías y estructuras organizacionales.

Uso en el proyecto:

Representar la estructura de niveles jerárquicos según los arboles generados en Random Forest.

Test and Score

Evalúa el rendimiento de diferentes modelos de aprendizaje automático.

Uso en el proyecto:

Comparar la precisión de árbol de decisión vs random forest

Save Data

Exporta el conjunto de datos procesado a diversos formatos de archivo.

Uso en el proyecto:

Guardar los datos finales para análisis posteriores.

Objetivo del Análisis

"¿Cómo influyen el nivel de entidad, el orden y el valor total de la experiencia en el nivel jerárquico de un servidor público?"

Mediante Orange Data Mining, analizamos datos de servidores públicos para:

  • * Identificar correlaciones entre experiencia laboral, nivel de entidad y orden administrativo y nivel jerárquico, asimismo evaluar el impacto de estas con el objetivo.
  • * Generar descubrimientos valiosos sobre patrones de carrera pública.

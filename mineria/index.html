Proceso de descubrimiento de patrones y conocimientos útiles en grandes conjuntos de datos

¿Qué es la Minería de Datos?

La minería de datos es el proceso de descubrir patrones, correlaciones y conocimientos útiles a partir de grandes conjuntos de datos mediante técnicas estadísticas, de aprendizaje automático y visualización.

En nuestro proyecto, aplicamos minería de datos para:

  • Identificar relaciones entre variables
  • Descubrir patrones ocultos en los datos
  • Predecir tendencias basadas en datos históricos
  • Visualizar información compleja de manera comprensible

Objetivo del Análisis

"¿Cómo influyen el nivel de entidad, el orden y el valor total de la experiencia en el nivel jerárquico de un servidor público?"

Mediante Orange Data Mining, analizamos datos de servidores públicos para:

  • * Identificar correlaciones entre experiencia laboral, nivel de entidad y orden administrativo y nivel jerárquico, asimismo evaluar el impacto de estas con el objetivo.
  • * Generar descubrimientos valiosos sobre patrones de carrera pública.

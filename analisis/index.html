Objetivo del Análisis

"¿Cómo influyen el nivel de entidad, el orden y el valor total de la experiencia en el nivel jerárquico de un servidor público?"

Mediante Orange Data Mining, analizamos datos de servidores públicos para:

  • * Identificar correlaciones entre experiencia laboral, nivel de entidad y orden administrativo y nivel jerárquico, asimismo evaluar el impacto de estas con el objetivo.
  • * Generar descubrimientos valiosos sobre patrones de carrera pública.

🌲 ¿Qué nos dijo el Árbol de Decisión (Tree)?

Este modelo construye una especie de “árbol” de decisiones que va separando los datos en función de la variable más influyente. En este caso, la experiencia total en meses fue la única utilizada para crear ramas (nodos), lo que muestra que tiene una fuerte relación con el nivel jerárquico.

  • En general, el nivel Profesional fue el más frecuente, sobre todo cuando los años de experiencia eran bajos o medios.
  • En entidades de orden nacional con más de 111 meses de experiencia, el 61% de los cargos seguía siendo Profesional.
  • En entidades descentralizadas o territoriales con menor experiencia, la concentración en este nivel era aún mayor.
  • Esto indica que, aunque la experiencia ayuda a clasificar, muchas personas con experiencia siguen ocupando cargos intermedios.

🌳 ¿Qué nos mostró el Bosque Aleatorio (Random Forest)?

Este modelo combina muchos árboles como el anterior, pero toma decisiones más complejas considerando varias variables al mismo tiempo. Aquí se usaron: experiencia total, orden y nivel de entidad.

  • El cargo Inspector de Seguridad Aérea apareció como el más común en muchos nodos.
  • Cuando la experiencia era mayor (más de 837 meses), otros cargos como Especialista o Administrativo comenzaron a tener mayor presencia.
  • Este modelo mostró una mayor diversidad de cargos cuando se combinaban experiencia con el tipo de entidad y orden.
  • Aunque complejo, confirmó el patrón: la experiencia y el entorno institucional marcan diferencias jerárquicas claras.

¿Qué nos dicen las métricas?

AUC (Área bajo la curva ROC)

Imagina que el modelo intenta distinguir correctamente el nivel jerárquico de un servidor público, basándose en datos como su experiencia total, nivel de entidad y orden. Un AUC de 0.5 sería como adivinar al azar, sin ninguna guía. Aquí tenemos 0.54, lo que significa que el modelo puede diferenciar un poco mejor que el azar entre niveles jerárquicos, pero aún es una señal débil. Es un primer indicio de que algunos patrones existen en los datos, aunque necesitamos más información o modelos para mejorar.

Precisión general (Accuracy)

De cada 100 servidores públicos, el modelo predice correctamente el nivel jerárquico en aproximadamente 49 casos (para el árbol de decisión). Esto indica que el modelo está aprendiendo algo sobre cómo características como experiencia o tipo de nombramiento influyen en el nivel jerárquico, pero todavía se equivoca en la mayoría de los casos.

F1-Score

Esta métrica balancea dos cosas importantes: que el modelo no se equivoque mucho al predecir un nivel jerárquico (precisión) y que identifique la mayor cantidad posible de servidores que realmente pertenecen a ese nivel (recall). Un valor cerca de 0.4 indica que el modelo es moderadamente bueno para clasificar niveles jerárquicos, pero aún puede mejorar para no dejar pasar servidores en niveles importantes o para no clasificarlos erróneamente.

Precisión (Precision)

De todos los servidores públicos a quienes el modelo asignó un nivel jerárquico específico, cerca del 38% corresponde realmente a ese nivel. Esto indica que, aunque no es muy confiable aún, el modelo tiene cierta base para hacer estas predicciones y puede perfeccionarse con más datos o mejores técnicas.

Recall (Sensibilidad)

De todos los servidores públicos que realmente pertenecen a un nivel jerárquico, el modelo logra identificar alrededor del 45-49%. Es decir, el modelo encuentra casi la mitad de los casos reales, un buen comienzo dado lo complejo que es predecir estos niveles con las variables disponibles.

Coeficiente de Correlación de Matthews (MCC)

Esta métrica muestra qué tan bien coinciden las predicciones del modelo con la realidad considerando todos los aciertos y errores. Aunque los valores son bajos (cerca de 0.05), indican que el modelo no está funcionando al azar completo y que hay una pequeña relación entre las variables como experiencia total o naturaleza jurídica y el nivel jerárquico.

Aunque el modelo no es perfecto y la precisión es moderada, sí se puede detectar una relación importante entre las características de los servidores públicos y su nivel jerárquico. El modelo de árbol de decisión, simple pero efectivo, funcionó mejor que el Random Forest, mostrando que incluso métodos básicos pueden ayudarnos a entender cómo se asignan los niveles jerárquicos y guiar mejoras futuras para una mejor gestión del talento público.

✅ Conclusiones Finales

  • La experiencia total en meses fue la variable con mayor poder explicativo.
  • El modelo Tree es más comprensible y eficiente, ideal para bases pequeñas y estructuradas.
  • Random Forest mostró patrones más ricos, pero fue menos preciso en este caso.
  • Se eligió esta tabla porque tiene una variable objetivo-clasificada y útil, donde sus variables predictoras son estructuradas, categorizadas o numéricas, en el que tiene datos completos y limpios, asimismo los tipos de datos coinciden con lo que estos modelos procesan de forma nativa.
  • Ambos modelos ayudan a comprender cómo factores como experiencia y tipo de entidad se relacionan con la jerarquía ocupada.

Este tipo de análisis puede generar insumos concretos para la formulación de políticas públicas y estrategias de gestión del talento humano. Por ejemplo:

  • Planeación de carrera y promociones: Ayuda a identificar si la experiencia está siendo reconocida de forma justa para acceder a cargos superiores.
  • Diseño de capacitaciones y programas de desarrollo: Al detectar grupos que tienen demasiadas personas en un mismo nivel (como el nivel Profesional), se pueden crear planes de crecimiento para evitar que se queden estancados.
  • Distribución del talento según tipo de entidad: Permite entender si los niveles jerárquicos varían según el orden (nacional vs territorial), lo que puede servir para focalizar incentivos o reformar estructuras.
  • Optimización de procesos de selección: Con base en patrones encontrados, se pueden ajustar criterios de selección para distintos cargos públicos.

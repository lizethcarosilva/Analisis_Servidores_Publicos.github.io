Fuente de Datos

datos.gov.co

Portal de datos abiertos del gobierno colombiano

  • Dataset: Conjunto de servidores públicos
  • Formato: CSV
  • Registros: 203,817 registros iniciales

Proceso de Obtención

  1. Visitar https://www.datos.gov.co/
  2. Buscar "Conjunto servidores públicos"
  3. Seleccionar "Exportar" → "CSV"
  4. Descargar archivo localmente
  5. Importar en Orange Data Mining
